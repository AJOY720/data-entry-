Data Entry & Record Management - PWA Application
===================================================

এই ফোল্ডারের ফাইলসমূহ:
1. index.html      - মূল ওয়েব অ্যাপ (ফর্ম, ডেটাভিউ, সার্চ এবং এক্সপোর্ট অপশন)
2. manifest.json   - PWA কনফিগারেশন ফাইল (অ্যাপের নাম, আইকন, কালার)
3. sw.js           - Service Worker স্ক্রিপ্ট (সম্পূর্ণ অফলাইনে চলার জন্য ক্যাশিং সুবিধা)
4. icon-192.png    - অ্যাপ আইকন (192x192)
5. icon-512.png    - অ্যাপ আইকন (512x512)

কীভাবে ব্যবহার করবেন:
--------------------
১. জিপ ফাইলটি আনজিপ (Extract) করুন।
২. সরাসরি ফাইলটি ব্রাউজারে খুলতে `index.html` ফাইলে ডাবল ক্লিক করতে পারেন।
৩. PWA হিসেবে মোবাইল বা কম্পিউটারে ইনস্টল করতে:
   - ফাইলগুলো যেকোনো লোকাল সার্ভার (যেমন VS Code Live Server, Python http.server) অথবা GitHub Pages / Netlify / Vercel-এ ফ্রিতে হোস্ট করুন।
   - ব্রাউজারে সাইটটি ওপেন করলে সরাসরি "📲 ইন্সটল অ্যাপ" বাটন দেখতে পাবেন এবং মোবাইল/পিসিতে অ্যাপ হিসেবে ইনস্টল করে অফলাইনে ব্যবহার করতে পারবেন।
